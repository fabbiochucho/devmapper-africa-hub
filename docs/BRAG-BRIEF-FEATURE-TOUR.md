# DevMapper Launch Video — Brief C: "Feature Tour"

For use with `/brag` or `/brag-slim`.

## Plot

A different creative mode than Briefs A/B — those are single-emotion
narratives (problem→fix→proof, invitation→payoff). A genuine *features*
tour needs to show real breadth, so instead of one throughline it's
structured as a confident, labeled walkthrough — closer to a product demo
reel. This deliberately runs longer than brag's usual 15–25s rule; that's a
conscious trade for breadth over a single emotional beat, not scope creep.

**Tone:** Same institutional confidence, but more "here's everything, fast"
than "here's a feeling." Each pillar gets a title card + real screen
capture — no voiceover explaining *how* anything works, just enough to
register *that* it exists.

**Length:** ~28 seconds, 8 shots (open + 6 feature pillars + close).

**Why six pillars, not more:** Report, Verify, Measure (ESG/carbon), Manage
(PM), Connect (community), Everywhere (language/responsive) covers every
module this session actually built without turning into a feature-dump.
Anything finer-grained (e.g. splitting ESG into emissions/suppliers/
scenarios/IFRS separately) needs its own longer video — see Brief E.

**Deliberately cut:** admin/back-office tooling (certification review,
broadcasts, data provider registry) — real, but not demo-reel material;
nobody outside your own admin team needs to see it in a launch video.
