# DevMapper Launch Video — Brief E: "ESG Deep Dive — Four Chapters"

For use with `/brag` or `/brag-slim`. This is the finer-grained,
longer-form piece Brief C (Feature Tour) deliberately declined to be.

## Plot

Four real tabs from the ESG module (`src/components/esg/`), each getting
an actual chapter instead of a half-second flash: Emissions, Suppliers,
Scenarios, IFRS Readiness. No single emotional arc — each chapter closes
its own loop (the problem the tab solves → the actual screen → the output
it produces).

**Length:** ~48 seconds, 4 chapters + open/close. This openly breaks
brag's "15–25s" short-form rule — a deliberate trade for depth over a
single beat, same reasoning as Brief C.

**Why four chapters, not six:** the Benchmarks/Verification/Frameworks/
Reports tabs are real too, but Emissions/Suppliers/Scenarios/IFRS is the
actual regulatory-compliance narrative (measure → account for your chain →
model your path → prove you're on it) — the other tabs support that story
rather than extending it.
